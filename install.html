我的品飲手冊　安裝說明

一個給上課用的葡萄酒品飲筆記工具。不用到商店下載，用手機瀏覽器開網址、加到主畫面就能用，約一分鐘。

測試中免費iPhone／Android

掃 QR code，或複製網址

https://mo-tsai.github.io/sipnote-4k7q/

請用 Safari（iPhone）或 Chrome（Android）打開。從 LINE 裡直接點開的內建瀏覽器，沒有「加入主畫面」這個選項。長按連結選「在瀏覽器開啟」，或把網址貼到 Safari／Chrome。

iPhone

用 Safari 加入主畫面

  1. 用 Safari 打開網址。
  2. 按螢幕下方中間的分享鍵（方框加向上箭頭）。
  3. 往下找到「加入主畫面」，按右上角「加入」。
  4. 主畫面多了一個酒紅色酒杯圖示，之後從那裡打開。

Android

用 Chrome 安裝

  1. 用 Chrome 打開網址。
  2. 按右上角的「⋮」選單。
  3. 選「安裝應用程式」（有些手機寫「加到主畫面」），再按「安裝」。
  4. 主畫面會出現圖示，之後從那裡打開。

電腦（Chrome／Edge）

網址列右側會有「安裝」的小圖示，按下去就會變成一個獨立視窗的 App。

用之前請記得兩件事

1. 你的筆記只存在自己的手機裡，沒有上傳到任何地方。換手機、清掉瀏覽器資料、或移除 App，筆記就會不見。

2. 請固定到「設定」按「匯出備份」，把檔案存到雲端硬碟或寄給自己。建議一個月一次。

常見問題

可以用電腦打開嗎

可以，用 Chrome 或 Edge。手機和電腦的筆記不會自動同步，要靠「匯出備份」和「匯入備份」搬。

酒標辨識要自己申請金鑰嗎

那是選用功能，用 Gemini 的免費 API，要自己建一把金鑰才能用。不用也完全可以，所有勾選和記錄都照常。想用的話，在 App「設定」頁有圖文教學。

會收集我的資料嗎

不會。這個 App 沒有帳號、沒有上傳，筆記只存在你的手機。如果你用酒標辨識，被選的照片會直接送到 Google Gemini（你自己的金鑰），不會經過其他地方。
